# CLAUDE.md

## Project Identity

This repository is a Vite + React 18 portfolio website for `erkindilekci.com`.

The goal is to build a modern, clean, visually impressive, and highly professional portfolio focused on:

- Data Analyst roles
- Business Intelligence roles
- Data Engineer roles
- Junior Data Scientist roles
- Data-driven software development
- Industrial Engineering + analytics background

The site should feel polished, credible, fast, and recruiter-friendly. Avoid generic portfolio templates. Prioritize a strong first impression, clear storytelling, measurable impact, and modern UI details.

## Tech Stack

- Vite
- React 18
- Tailwind CSS
- react-icons
- million/compiler

Main files:

- App entry point: `src/main.jsx`
- Root UI: `src/App.jsx`
- Main sections: `src/components/main/`
- Data/content files: `src/assets/data/`
- Resume PDF: `public/ErkinDilekci.pdf`
- Resume URL source: `src/assets/data/profile.js`
